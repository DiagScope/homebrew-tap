Warning N_PLUS_ONE_QUERY_RISK OrderService.java:61 MEDIUM confidence

Repository call findByOrder() is inside a loop — one query per iteration. For a list of 100 orders this issues 101 database roundtrips where a single JOIN or batch fetch would do.

Flow path

OrderService.java · lines 59–63
for (Order order : orders) {
    List<Item> items = orderItems.findByOrder(order.id()); // N queries
    order.setItems(items);
}
How to fix

Use orderItems.findByOrderIdIn(orderIds) to load all items in one query, then associate them in memory with a Map grouping by order ID. Or configure the JPA relationship with fetch = FetchType.EAGER and a JOIN fetch in the parent query.
